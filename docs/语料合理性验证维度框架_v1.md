# 语料合理性验证维度框架（v1）

> 整理日期：2026-09-01　|　项目：斯瓦希里语（sw-KE）TTS 回流语料分析
> 定位：**框架文档**——定义每个验证维度的「算什么、怎么算、阈值多少、产出什么」。数据实测在流水线开工后填数。
> 上游文档：《TTS回流语料分析与录音脚本构建_SOP_v1.md》（v1.1）、《实施计划 v2》
> 阈值均已锁定（见各表「阈值」列），不再重复讨论。

## 总览：五大验证维度

```
语料合理性验证
├── V1 合法性        —— 句子「能不能用」：字符/语言/长度门槛
├── V2 句式分布      —— 句子「像不像真实使用」：疑问/感叹/陈述配比
├── V3 词汇分布      —— 词表「覆盖与倾斜」：词频/外来词/NSW
├── V4 音素分布      —— 音位层「覆盖与均匀」：TTS 覆盖率核心
└── V5 其他维度      —— 情感、词源、内容形态等辅助信号
```

数据源：主 sheet `录音文本`（2,912 有效行），文本列 `clean_text(录音用)`；语言列 `语言`（pure_sw 2614 / code_switch 218 / sw_presumed 80）与内容形态列直接复用，**不重新推断**。

## V1 合法性（Gate 1 的展开）

### V1.1 字符集合法性

- **定义**：每句字符是否都在目标语言合法字符集内。
- **方法**：构建斯语合法字符白名单 = `a-z` 基础集 + 五元音（正字法 23 字母）+ `'`（**ng' 撇号是正字法区分符，必须白名单保留，禁止当标点清洗**）。逐句扫出白名单外字符（emoji、中文、阿拉伯字符、全角符号等），输出字符类别直方图。
- **判定**：白名单外字符 → 标记该句进入 `code_switch` 或 `需清洗` 子流程，不直接剔除（英文词在 code_switch 句合法）。
- **阈值**：无硬性——产出为「非法字符分布表」，供清洗规则定稿。
- **产出物**：Excel sheet `字符集审计`（字符 → 出现次数 → 涉及句数 → 示例）。

### V1.2 目标语言判定

- **定义**：句子主体是否为目标语言（sw）。
- **方法**：复用已有 `语言` 列（pure_sw / code_switch / sw_presumed），**不重新推断**；补充抽验 sw_presumed 80 句的判定质量（抽样 20 句人工/词典核对）。
- **阈值**：sw_presumed 抽验错误率 >20% → 该 80 句降级处理。
- **产出物**：sheet `语言分层`（三分布计数 + sw_presumed 抽验结果）。

### V1.3 长度分布（四项）

| 指标       | 定义                                                              | 方法                                                   | 阈值（已锁定）                                                                        |
| ---------- | ----------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| 单句字符数 | len(clean_text)                                                   | 直方图 + 分位数                                        | **主集门控 20–300 字符**；>300 的 1,037 句（含 22,535 病态句）单独归档不进主集 |
| 单句单词数 | whitespace 分词计数                                               | 直方图                                                 | **录音句 5–30 词**（≈2–15 秒）                                               |
| 单词长度   | 全语料 token 长度                                                 | 词长直方图（1–20+ 字符）                              | 观测项：斯语典型词 4–8 字符；>15 字符多为复合/粘连，人工抽查                         |
| 单句音节数 | 规则计数：每元音组一个音节峰（斯语无复元音歧义，VV 序列按规则拆） | `音节数 ≈ 元音簇数`，用 config_sw 的 SYLLABLE_RULES | 参照词数×2±1 校准；目标录音句 ≈4–60 音节                                          |

- **产出物**：sheet `长度分布`（四组直方图数据 + 门控前后行数对照）。

## V2 句式分布（Gate 3 的展开）

- **定义**：疑问句 / 感叹句 / 陈述句 / 短语（片段）的占比是否符合真实语音助手语感。
- **方法**：先规则分类——
  - 疑问句：句尾 `?` 或疑问词开头（Je, / Ni / Nani / Nini / Lini / Wapi / Gani / Ngapi / Kwa nini…）
  - 感叹句：句尾 `!`
  - 短语：无句末标点且 <5 词
  - 其余 → 陈述句
    规则结果抽样 30 句人工核对分类准确率，<90% 调规则。
- **阈值（已锁定，Azure 口径）**：| 句式 | 目标配比 |
  | ---- | -------- |
  | 陈述 | 70–80%  |
  | 短语 | ~10%     |
  | 疑问 | 10–20%  |
  | 感叹 | 10–20%  |
- **产出物**：sheet `句式分布`（四类计数/占比 + 与目标配比差距 + 偏差告警）。
- **注意**：回流语料偏陈述是常态（助手回复多为陈述句），若感叹/疑问不足，选句阶段从富余句式补，或在扩语料计划中列入。

## V3 词汇分布（Gate 4 的展开）

### V3.1 词频表

- **定义**：全语料 token（小写、保留 `'`）的频次排序表。
- **方法**：分词 → 计数 → 排序。输出 Top100 / 全表。
- **配套指标（阈值已锁定）**：| 指标        | 含义                             | 阈值                                                                 |
  | ----------- | -------------------------------- | -------------------------------------------------------------------- |
  | 覆盖率      | 出现 ≥N 次的词占 token 总量比例 | —（观测）                                                           |
  | H_norm      | 归一化香农熵（0–1）             | ≥0.90 很均匀 / 0.75–0.90 较均匀 / 0.60–0.75 中等 / <0.60 严重倾斜 |
  | Gini        | 词频集中度                       | >0.6 高度集中                                                        |
  | Top10% 占比 | 最高频 10% 词的 token 份额       | >80% 严重集中                                                        |
  | CV          | 变异系数                         | 仅辅助                                                               |
- **产出物**：sheet `词频表`（Top100+全表）+ `词汇均匀性`（指标值）。

### V3.2 外来词占比

- **定义**：非斯语来源词（英语借词、未融合英语词、阿拉伯/印地借词）占比。
- **方法**：三层判断——① ipa-dict sw 词典命中（48,308 条）→ 斯语；② 在 code_switch 句内且拼写为英语高频词 → 英语词；③ `生僻词候选`4594 词的 ety 标签（prompt v1 词源标注）回填。
- **阈值**：观测项。英语未融合词在 pure_sw 句中占比过高（>10%）→ 提示语码切换边界噪声。
- **产出物**：sheet `外来词`（来源分类计数 + Top 列表）。

### V3.3 实词 / 虚词占比

- **定义**：content words（名词/动词/形容词）vs function words（代词/助词/介词/连词）比例。
- **方法**：斯语虚词集是封闭类（na, wa, ya, kwa, ni, ya, cha…前缀系 + 常用功能词表 ~150 词），先词典法分类，残差人工抽 50 词归入。
- **阈值**：观测项；虚词过高（>50% token）提示语料偏寒暄/短句。
- **产出物**：sheet `实虚词`。

### V3.4 非标准词 NSW 占比

- **定义**：Non-Standard Words——数字、时间、货币（KSh）、电话号码、缩写、网址、英文缩略（OK/APP）。
- **方法**：正则规则表（config_sw 的 NSW_PATTERNS）：`\d+`、`\d+[:.]\d+`、`KSh\s*\d`、`\+254`、`[A-Z]{2,}` 等；逐句扫描计数。
- **阈值**：观测项；NSW 句占比直接决定 TN 规则的优先级排序（命中高的 pattern 先写）。
- **产出物**：sheet `NSW分布`（pattern 类型 → 命中句数 → 示例）→ **直接生成 TN 规则工作清单**。

## V4 音素分布（Gate 5/6 的展开，TTS 覆盖率核心）

> 前置依赖：G2P（自研规则表 or epitran 校验层）跑完全语料。**同时支持 grapheme-only 模式**（字位 bigram/trigram，与音位版并列输出）——引擎不吃音素时以字位版为准。

### V4.1 单字母（grapheme）分布

- **定义**：26 字母 + `'` 的频次与覆盖率。
- **方法**：全文 token 化后逐字符计数；白名单外字符已在 V1.1 处理。
- **阈值**：核心字母覆盖率 ≥5 次（音频侧覆盖），频次表长尾 ≥3 次。

### V4.2 单音素（phoneme）分布

- **定义**：config_sw PHONE_TABLE 全音素的语料覆盖。
- **方法**：G2P 全量转写 → 音素计数。特别关注：
  - 前鼻化 mb/nd/nj/ng/mv/nz：**按单音位统计 + 另出 N+C 丛对照**（两版都进报表，学界口径不一）；
  - `ng'` /ŋ/ vs `ng` /ᵑɡ/：分开统计验证区分度；
  - 阿拉伯边缘擦音 th/dh/gh/kh：标 marginal，**不进核心音素表**；
  - 成音节鼻音（m̩ / n̩，如 mtoto 首音节）单独计数。
- **阈值**：核心音素 ≥5 次、长尾 ≥3 次；H_norm 同 V3.1 阈值表。

### V4.3 音素组合（bigram / trigram）分布

- **定义**：音素级 bigram/trigram 的覆盖与均匀性——diphone 式覆盖的代理指标。
- **方法**：滑动窗口计数；与 COMBINATION_SPACE（理论可组合空间，由 config_sw 元音×辅音×鼻化规则生成）做差集 → **缺失组合清单**（选句阶段贪心补齐的目标）。
- **阈值**：理论空间内高频组合（语料天然可含的）≥3 次；理论空间外出现 → 音素表越界告警（联动 Phoible sw 音位清单校验）。

### V4.4 graph→phoneme 一致性抽验

- **定义**：G2P 输出可信度抽验。
- **方法**：随机抽 100 词，与 ipa-dict sw 词典对照；不一致处人工裁决（espeak/epitran/transphone 三方参照）。
- **阈值**：一致率 <95% → 修规则表再验。
- **产出物**：sheet `音素分布`（单音素表）/ `音素组合`（bigram/trigram 表）/ `缺失组合`（选句输入）/ `G2P抽验`。

## V5 其他维度

### V5.1 情感分布

- **定义**：中性/积极/消极/疑问语气的粗分布（回流助手语料预期中性占绝对多数）。
- **方法**：词表法（斯语情感小词表：asante/sawa/pole/pongzi… + emoji 映射），残差不管。**不追求精确，只提示录音风格配比**。
- **阈值**：观测项。
- **产出物**：sheet `情感分布`。

### V5.2 词源分布

- **定义**：ety 标签（班图/阿拉伯/英语/印地…来源）分布——联动《生僻词与词源 prompt v1》对 4594 词的全量打标。
- **方法**：prompt v1 打标结果汇总（≤300 词/批，断点续跑）。
- **阈值**：观测项；阿拉伯来源词占比高 → marginal 擦音的录音必要性上升。
- **产出物**：sheet `词源分布`。

### V5.3 内容形态复用

- **定义**：主表已有 `内容形态` 列归一化后复用（问答/指令/闲聊/系统提示…）。
- **产出物**：sheet `内容形态`（归一化映射表 + 分布）。

## 执行顺序与依赖

```
V1 合法性（无依赖，最先跑）──┐
V2 句式分布（无依赖）────────┤
V3 词汇分布（需分词+ipa-dict）┤
                              ├─▶ V4 音素分布（需 G2P 定稿）─▶ 选句脚本
V5 词源（需 prompt v1 打标）─┘
```

- V1/V2/V3 可与 config_sw.py 定稿并行；
- V4 必须等 G2P 规则表定稿（否则音素集会变）；
- 全部结果汇总进 **Excel 总报表（15 sheet 设计）**。
